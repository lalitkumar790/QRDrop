OFFLINE FILE TRANSFER

Move a file with a screen and a camera.

QRDrop turns your file into a series of QR codes. Show them on one device and scan them with the other. The file travels optically, not through a server.

No cloud storage. No automatic copies.

Received files stay in this browser tab until you choose Save file. Nothing is saved to your device automatically. Close the tab before saving, and the unsaved file is gone.

Before you start

Open QRDrop on both devices while online once so the app can be cached. Then turn off Wi-Fi and mobile data on both devices before transferring. Camera scanning needs a supported browser and permission.

Simple by design

No server in the transfer

File data moves as visible QR codes from one screen to the other. There is no file upload, cloud storage, network relay or WebRTC connection.

You decide what gets saved

The reconstructed file stays in browser memory until you choose to save it. QRDrop does not automatically download or retain a copy.

A practical limitation

QR transfer is slower than a network transfer. The receiver needs HTTPS, camera permission and a browser that supports camera QR scanning.

One privacy note: QR frames are not encrypted. Someone who can capture the complete sequence could reconstruct the file, so avoid transferring sensitive files where other people can see the screen.
